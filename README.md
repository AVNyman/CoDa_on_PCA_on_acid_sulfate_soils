# CoDa_on_PCA_on_acid_sulfate_soils
Here you will find all the code and excel-files used in the the paper "New insights into acid sulfate soil geochemistry using multivariate compositional data analysis"


CoDa_PCA_Acid_Sulfate_soil.Rmd is the main file, containing every step, and uses Aqua_regia22.xlsx and LOI_22Sites.xlsx for its code.

rda_clr_loi_zone.MF.r are only the RDA analysis (also included in the above file), and is based on SiteData.csv and clrChem.csv.
